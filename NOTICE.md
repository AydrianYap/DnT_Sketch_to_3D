# Notice and attribution

**D&T Sketch-to-3D** is an educational adaptation of **PIXFORM**, made for a
Secondary 2 Design & Technology figurine project in Singapore.

## Original project

- **PIXFORM - Image to 3D**, by David Monfrooij
- Source: <https://github.com/dmonfrooij/pixform>
- Licence: GNU General Public License v3.0 (see [`LICENSE`](LICENSE))

PIXFORM provides the local image-to-3D engine (TripoSR, Hunyuan3D-2, TRELLIS and
TRELLIS.2 integrations), mesh post-processing, and the STL/3MF/GLB/OBJ export
that this project keeps and builds on.

## This adaptation

This adaptation is distributed under the same licence, **GPL-3.0**. You may use,
study, change and share it, but if you share a modified version you must share
its source code under GPL-3.0 too, and keep this notice and the licence.

The main changes so far (see `git log` for detail):

- The remote TRELLIS.2 "endpoint-first" mode was removed, so uploaded images
  are never sent to an outside AI service.
- AI models are limited to an approved list (`DNT_ALLOWED_MODELS`, default
  `triposr`) until each model's licence has been checked for classroom use.
- New classroom print preparation in `backend/dnt/`: uniform scaling into a
  40 x 40 x 60 mm box, optional flat base, and printability checks
  (watertight, manifold, separate parts, minimum thickness).
- PIXFORM's clean-up kept only the largest part of a mesh; now only tiny noise
  is removed and real separate parts are reported to the student.
- Development mode (`DNT_DEV_MODE=1`) with original sample sketches and meshes,
  so the app can be tested without a GPU.
- Upload limits (file type and size).
