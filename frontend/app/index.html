Tips for a good result
  • Draw one figurine on plain white paper.
  • Colour and shade it. Shading helps the AI understand depth.
  • Draw it from the front, or turned slightly (a three-quarter view).
  • Photograph straight on, in good light, with no shadows across the page.
  • Crop close around your figurine.

    How to save on iPad and open in Bambu Studio
    1. Tap Download 3MF (or STL). Safari asks to download: tap Download.
    2. The file is saved in the Files app, in Downloads.
    3. Send it to the computer that runs Bambu Studio (AirDrop, school drive, or as your teacher says).
    4. In Bambu Studio: File → Import → Import 3MF/STL. The size is already in millimetres, so do not scale it.

    Enter the access code

    The code is shown on the laptop that runs the 3D engine.
